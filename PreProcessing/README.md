Combined_Preprocessing.ipynb cleans NASA battery data
found at https://labinfo.ing.he-arc.ch/gitlab/ticc/16TICc19/nasa-battery-dataset/-/tree/master/data?ref_type=heads
It requires the use of Convert.py to import the converter class 
and the filepaths are required to be changed for the user's personal computer files
These cleaned parquet files are then used in the FPCA folder
